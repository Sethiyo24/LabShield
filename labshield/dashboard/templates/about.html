About LabShield

7th Semester Project · Single PC Exam Surveillance

About LabShield

LabShield is a silent exam surveillance system built for college practical labs. During a practical exam, students write code on a lab PC while LabShield runs invisibly in the background. Every action — DNS queries, window switches, clipboard pastes, file opens, USB mounts, and typing patterns — is logged with timestamps to a local SQLite database.

The philosophy is surveillance over blocking. Students are never blocked from any website or application. They have full freedom during the exam, but everything is recorded. After the exam, the teacher opens the dashboard at localhost:5000 and sees a complete evidence timeline with a suspicion score and optional AI verdict from Gemini Flash.

Detection Methods

🌐 DNS Monitor (Scapy)

Sniffs all DNS query packets on the network interface using Scapy. Captures every domain the student visits — including incognito/private browsing, because DNS queries happen at the OS level before the browser can hide them. Detects AI tools (ChatGPT, Gemini), search engines, online compilers, and messaging apps.

🪟 Window Monitor (pygetwindow)

Polls the active window title every 1 second. Logs when the title changes. Extracts page titles from browsers and filenames from IDEs. Flags suspicious titles like Gmail, Google Classroom, and Google Drive.

📋 Clipboard Monitor (pyperclip)

Polls clipboard content every 0.5 seconds. When content changes and is non-empty, logs the paste with character count and a 100-character preview. Pastes over 100 characters are flagged as suspicious large pastes (+30 points).

⌨ Keystroke Monitor (pynput)

Counts keypresses using pynput — never records actual key characters. Every 5 seconds, calculates typing rate (keys per second). Rates above 20 keys/sec indicate paste-like velocity (+30 points).

📁 File Monitor (watchdog)

Watches Desktop, Documents, home folder, and USB drive paths for file open and modify events. Flags code file extensions (.py, .java, .c, etc.) and any file accessed from a USB drive letter.

💾 USB Monitor (psutil)

Polls disk partitions every 2 seconds. Detects when a removable USB drive is mounted or removed within 2 seconds. USB insertion during an exam is flagged immediately (+25 points).

Why Each Method Works

Why DNS Sniffing Catches Incognito Mode

When a student opens an incognito browser window and visits chatgpt.com, the browser hides history and cookies — but it still sends a DNS query to resolve the domain name to an IP address. This query travels over the network at the OS level. Scapy captures these packets directly, bypassing all browser privacy features. The student cannot hide DNS queries without breaking their internet connection entirely.

Why HMAC Signing Matters

Every event row in SQLite is signed with HMAC-SHA256 using a secret key. The signature covers the timestamp, event type, and detail text. If anyone modifies a log entry after the exam — changing a timestamp or deleting an event — the signature will no longer match. This provides tamper-proof evidence that holds up during academic integrity reviews.

Why Keystroke Velocity Detects Paste

Human typing averages 4–8 keys per second. When a student pastes 200 lines of code, all characters appear in the editor within milliseconds — producing a rate of 50–200+ keys per second. LabShield never records what keys were pressed; it only counts how many keys per second arrived. A sudden spike above 20 keys/sec is strong evidence of paste.

Future Scope — 8th Semester Upgrade

The single-PC architecture in 7th semester is designed as a foundation for a distributed deployment in 8th semester. The same six monitor modules, rule engine, database schema, and dashboard design will be reused with minimal changes:

  • Deploy the agent to 60 student PCs simultaneously
  • Stream events to a central PostgreSQL server via WebSocket (FastAPI)
  • React dashboard showing all 60 students on one teacher screen
  • Redis for live state caching across 60 concurrent sessions
  • Docker + Nginx for production deployment
  • JWT authentication for teacher login
  • Batch AI verdicts for all students at once

Zero changes are needed to the monitor modules, rule engine logic, Gemini integration, or database schema — only the transport layer and dashboard scale up.
